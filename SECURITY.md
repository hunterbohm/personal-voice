# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing message data, credentials, local paths, or details that would help reproduce a privacy leak against a real corpus.

Include the affected version, a synthetic reproduction, and the expected privacy boundary. Replace every real identifier and message before attaching logs or fixtures.

## Supported versions

Until the first stable release, security fixes apply to the latest commit on `main` only.

## Scope

Security and privacy reports may cover source ingestion, permissions, Git-boundary checks, retrieval disclosure, local endpoint validation, renderer guards, artifact integrity, memorization probes, and activation gates.
